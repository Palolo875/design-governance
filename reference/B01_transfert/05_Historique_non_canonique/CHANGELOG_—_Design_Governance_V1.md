# CHANGELOG — Design Governance V1

## V1.0.0 — release initiale

**Statut :** version active et canonique.  
**Date :** 2026-08-20.  
**Owner d’acceptation :** propriétaire du corpus.  
**Noyau :** `DIRECTION.md`, `ACTION.md`, `SAVOIR.md`, `BIBLIOTHEQUE.md`, `CHANGELOG.md`.

V1.0.0 établit un noyau de gouvernance pour les runs de design et de production. `DIRECTION` choisit le mode, les absolus et la direction ; `ACTION` porte les traces, preuves, gates, verdicts et clôtures ; `SAVOIR` porte le jugement, le craft, le contexte, les sources et l’intégrité ; `BIBLIOTHEQUE` porte les structures et leurs contrats ; ce fichier porte l’état du package et ses changements futurs.

La version active exige que les preuves soient adaptées à leur portée, inspectables et fraîches par rapport à l’artefact livré. Elle protège le craft dominant par une opération de comparaison lorsqu’elle est applicable, distingue une revue indépendante d’une revue exposée, et conserve les traces persistantes au moyen d’un locator. Elle maintient les limites honnêtes : aucune preuve perceptuelle, technique ou experte ne devient par simple étiquette une preuve de tâche, de population, d’accessibilité complète ou de performance universelle.

## Politique de changement à partir de V1

Toute évolution future est ajoutée ici dans l’ordre chronologique. Une entrée indique le problème, le périmètre, la décision, le remplacement, les compatibilités, le propriétaire, la preuve, la limite, la condition de revue et le rollback. Une règle partagée n’est modifiée que dans son propriétaire canonique ; un exemple local, une préférence ou une observation isolée reste local jusqu’à preuve suffisante.
